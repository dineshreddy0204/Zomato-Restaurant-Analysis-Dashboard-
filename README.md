## 📊 Project Overview

This project demonstrates **end-to-end Power BI dashboard development** for restaurant analytics, showcasing:
- Interactive KPI tracking and performance monitoring
- Geographic analysis and location-based insights
- Customer behavior and ratings analysis
- Revenue and operational metrics
- Advanced Power BI features (slicers, maps, DAX calculations)

**Ideal For:** Recruiters evaluating Power BI dashboard design, data visualization, and business intelligence capabilities.

## 🎯 Business Problem

Restaurant chains need real-time visibility into:
- Which restaurants perform best geographically
- How ratings impact revenue and customer traffic
- Price positioning and competitive analysis
- Operational efficiency metrics
- Growth opportunities by location and cuisine type

**Solution:** Interactive Power BI dashboard enabling data-driven decision-making for restaurant management.

## 🚀 How to Use

### **Access the Dashboard:**
1. Open `Zomato_Dashboard.pbix` in Power BI Desktop
2. Refresh data connections if needed
3. Interact with slicers to filter by city, cuisine, or price range
4. Hover over visualizations for detailed insights
5. Use the drill-down feature for restaurant-level details

### **Customize for Your Needs:**
- Add new data sources (real-time restaurant data)
- Create additional measures using DAX
- Modify color schemes and branding
- Add forecasting using Python integration
